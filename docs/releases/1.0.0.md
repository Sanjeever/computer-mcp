# Computer MCP 1.0.0

[简体中文](https://github.com/Sanjeever/computer-mcp/blob/v1.0.0/docs/releases/1.0.0.zh-CN.md)

Computer MCP's first stable release supports native desktop observation and input over stdio MCP on macOS 14+ (Apple Silicon) and Windows 10/11 (x64). The npm launcher requires Node.js 22+. Desktop control requires a logged-in graphical session.

## Highlights

- Observe accessibility trees or screenshots, then click, type, send key chords, scroll, and drag. Window and desktop snapshots support coordinate input. Snapshots expire, and callers use the latest image and references for actions.
- Request a follow-up observation after input. Windows can follow verified menus and owned dialogs. macOS offers opt-in local OCR with English and Simplified Chinese recognition.
- Draw consecutive strokes from one window snapshot with `computer_batch`. The result reports which strokes were sent and can return one fresh screenshot after the batch.
- Install the launcher as `@sanjeever/computer-mcp`. npm selects the matching precompiled platform package. A source build can still be launched by its absolute path. See the [setup guide](https://github.com/Sanjeever/computer-mcp/blob/v1.0.0/README.md).

## Known limits

- Windows OCR is unavailable in this distribution. Elevated windows and secure desktops are subject to Windows input restrictions.
- macOS may report a sheet or modal blocker by description. Observe the visible area in a desktop crop when a separate window ID is unavailable.
- The native packages ship without Apple Developer ID signing or notarization and without Windows Authenticode signing. Upgrades may require granting macOS permissions again.

## Verification

Local verification on Apple Silicon covered the Go and TypeScript suites, installing the macOS tarballs, and MCP startup through the installed executable. The macOS desktop fixtures exercised Unicode input, capture, mixed-language OCR, modal detection, and drawing through stdio. The Windows x64 server and test executables cross-compiled. Windows desktop interaction and permission attribution in other MCP clients require their own interactive checks. The tagged [Release workflow](https://github.com/Sanjeever/computer-mcp/actions/workflows/release.yml) records the build and package checks for the published artifacts.
