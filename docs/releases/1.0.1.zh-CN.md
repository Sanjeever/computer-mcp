# Computer MCP 1.0.1

[English](https://github.com/Sanjeever/computer-mcp/blob/v1.0.1/docs/releases/1.0.1.md)

## 变更

- Windows 控件的原生窗口句柄已销毁时，即使 UI Automation 仍能解析该控件，也会返回 `stale_snapshot`。再次操作前请重新观察目标。
- Windows 桌面测试验证窗口截图和屏幕截图能反映画面更新，并加入专用 WPF 夹具。测试也覆盖裁剪缩放后的鼠标坐标、遮挡点拒绝，以及绘图后的后续截图。

## 升级

如果固定了 npm 版本，请改为 `@sanjeever/computer-mcp@1.0.1` 并重启 MCP 客户端。 [接入指南](https://github.com/Sanjeever/computer-mcp/blob/v1.0.1/README.zh-CN.md)

## 验证范围

在单显示器、100% 缩放的 Windows 10 x64 虚拟机上，本地构建的 tarball 通过离线安装，启动器通过 stdio 冒烟测试。使用已安装的原生服务运行截图、绘图、对话框、菜单和所属弹层夹具，连续两轮通过。全套夹具仍偶发鼠标事件缺失修饰键状态，已在 1.0.0 代码上复现。

标签触发的 [Release 工作流](https://github.com/Sanjeever/computer-mcp/actions/workflows/release.yml) 记录了发布产物的构建和安装检查。
