# Computer MCP 1.0.0

[English](https://github.com/Sanjeever/computer-mcp/blob/v1.0.0/docs/releases/1.0.0.md)

Computer MCP 首个稳定版通过 stdio MCP 提供原生桌面观察和输入，支持 macOS 14+（Apple Silicon）和 Windows 10/11（x64）。npm 启动器要求 Node.js 22+。桌面操作要求用户已登录图形会话。

## 功能

- 通过无障碍树或截图观察窗口，再点击、输入文本、发送组合键、滚动或拖拽。窗口和桌面快照均可用于坐标操作。快照会过期，输入应使用最新图片和引用。
- 输入后可请求后续观察。Windows 支持跟随已验证的菜单和所属对话框。macOS 提供按需启用的本地 OCR，支持英文和简体中文识别。
- 使用 `computer_batch` 在同一张窗口截图上连续绘制多笔。结果逐笔报告发送状态，并可在批次完成后返回一张新截图。
- 安装启动器 `@sanjeever/computer-mcp`，npm 会选择匹配的预编译平台包。从源码构建的程序仍可通过绝对路径启动。[接入指南](https://github.com/Sanjeever/computer-mcp/blob/v1.0.0/README.zh-CN.md)

## 已知限制

- 当前 Windows 分发版不提供 OCR。以管理员权限运行的窗口和安全桌面受 Windows 输入限制。
- macOS 部分 sheet 或其他模态阻塞会返回描述。没有独立窗口 ID 时，可裁剪桌面截图观察其可见区域。
- 原生平台包尚未采用 Apple Developer ID 签名与公证或 Windows Authenticode 签名。macOS 升级后可能需要重新授权。

## 验证范围

Apple Silicon 本地验证覆盖 Go 和 TypeScript 测试、macOS tarball 安装，以及通过已安装入口启动 MCP。macOS 桌面夹具覆盖 Unicode 输入、截图、混合中英文 OCR、模态阻塞检测及通过 stdio 绘制。Windows x64 服务和测试程序完成交叉编译。Windows 桌面交互和其他 MCP 客户端的权限归属需分别做实机验收。标签发布产物的构建与安装检查见对应的 [Release 工作流](https://github.com/Sanjeever/computer-mcp/actions/workflows/release.yml)。
