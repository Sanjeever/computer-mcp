# Computer MCP 1.0.2

[English](https://github.com/Sanjeever/computer-mcp/blob/v1.0.2/docs/releases/1.0.2.md)

## 变更

- 在 Windows 上，给 `computer_click` 或 `computer_move` 传入 `capture_transition:{}`，即可在鼠标输入前后采样可见屏幕。结果包含带时间戳的帧时间线、像素变化范围和带标注的 JPEG 关键帧拼图。
- 默认采样 800 毫秒，目标为每秒 30 次。可通过 `duration_ms` 和 `region` 聚焦指定过渡。短暂的画面变化可能落在两次采样之间。[过渡采集指南](https://github.com/Sanjeever/computer-mcp/blob/v1.0.2/docs/usage.zh-CN.md#工具)

## 升级

如果固定了 npm 版本，请改为 `@sanjeever/computer-mcp@1.0.2` 并重启 MCP 客户端。[接入指南](https://github.com/Sanjeever/computer-mcp/blob/v1.0.2/README.zh-CN.md)

## 验证范围

Windows stdio 测试在专用 Win32 画布上触发点击和悬停变化。两次 300 毫秒采集各取得 10 个样本，包含基准帧和输入后的可见变化。Go 测试和 `go vet` 在 Windows 上通过。本地构建的启动器和 Windows 原生 tarball 通过离线安装与 stdio 冒烟测试。

标签触发的 [Release 工作流](https://github.com/Sanjeever/computer-mcp/actions/workflows/release.yml) 记录了发布产物的构建和安装检查。
