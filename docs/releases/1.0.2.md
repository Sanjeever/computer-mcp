# Computer MCP 1.0.2

[简体中文](https://github.com/Sanjeever/computer-mcp/blob/v1.0.2/docs/releases/1.0.2.zh-CN.md)

## Changes

- On Windows, pass `capture_transition:{}` to `computer_click` or `computer_move` to sample the visible screen before and after mouse input. The result includes a timestamped frame timeline, pixel change bounds, and a labeled JPEG contact sheet.
- Sampling defaults to 800 ms and targets 30 samples per second. Set `duration_ms` and `region` to focus on a specific transition. Brief visual changes may fall between samples. [Transition capture guide](https://github.com/Sanjeever/computer-mcp/blob/v1.0.2/docs/usage.md#tools)

## Upgrade

Update any pinned npm version to `@sanjeever/computer-mcp@1.0.2` and restart the MCP client. [Setup guide](https://github.com/Sanjeever/computer-mcp/blob/v1.0.2/README.md)

## Verification

The Windows stdio tests triggered click and hover updates on a dedicated Win32 canvas. Each 300 ms capture recorded 10 samples, including a baseline and a visible change after input. The Go tests and `go vet` passed on Windows. The locally built launcher and Windows native tarballs passed offline installation and the stdio smoke test.

The tagged [Release workflow](https://github.com/Sanjeever/computer-mcp/actions/workflows/release.yml) records build and install checks for the published artifacts.
